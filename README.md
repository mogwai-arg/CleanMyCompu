# CleanMyCompu

Limpiador de sistema para macOS (y Windows en camino).

Descargá la última versión desde [Releases](https://github.com/mogwai-arg/CleanMyCompu/releases).

## Features

- Limpieza de cachés del sistema, navegadores y desarrollo
- Detección de restos de programas viejos (Adobe, Office, apps desinstaladas)
- Buscador de duplicados por hash
- Desinstalador con escalación a permisos de admin
- Gestor de agentes de inicio con recomendaciones
- Actualizador de paquetes Homebrew
- Memory Clean nativo
- Notificaciones cuando hay updates disponibles
